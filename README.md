# Jacqueline 工作台 · 手机版

一个**纯离线**的个人工作台网页 App：今日三件事、习惯打卡、体重与饮水、待办、心情日记、每日一句、法定节假日。

- 数据只存在手机本地（Safari 本地存储），**不上传任何服务器**
- 断网也能用（Service Worker 缓存）
- 莫兰迪配色 6 套可切换
- 417 句阳光词库，每天自动换一句
- 2025–2027 法定节假日与调休

## 安装（iPhone）

1. 用 **Safari** 打开本仓库的 Pages 地址（形如 `https://用户名.github.io/仓库名/`）
2. 点底部 **分享** → **添加到主屏幕** → 添加
3. 桌面上会出现靶心图标，点开就是全屏 App，断网可用

> 已添加过的同学：图标是缓存的，更新后请长按旧图标删除，再重新添加一次。

## 与电脑版同步

- 电脑 → 手机：电脑版「设置 → 导出数据给手机(.json)」→ 发到手机 → 手机版「我的 → 从备份恢复」
- 手机 → 电脑：手机版「我的 → 导出备份」→ 发到电脑 → 电脑版「设置 → 从备份恢复」

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 主程序（单文件，含全部界面与逻辑） |
| `manifest.webmanifest` | 桌面图标与名称配置 |
| `sw.js` | 离线缓存 |
| `icon-180/192/512-v3.png` | 桌面图标 |

## 提醒功能说明

网页 App 在后台不能定时弹通知，所以**提醒走系统日历**：
在电脑版「定时提醒 → 📱 导出到 iPhone 日历」生成 `.ics`，发到 iPhone 点开「添加到日历」，到点由系统提醒，电脑关着也没事。
