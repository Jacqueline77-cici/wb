# Jacqueline 工作台 · 手机版

一个**纯离线**的个人工作台网页 App：今日三件事、习惯打卡、体重与饮水、待办、心情日记、每日一句、法定节假日。

- 数据只存在手机本地（Safari 本地存储），**不上传任何服务器**
- 断网也能用（Service Worker 缓存）
- 莫兰迪配色 6 套可切换
- 417 句阳光词库，每天自动换一句
- 2025–2027 法定节假日与调休

## 安装（iPhone）

1. 用 **Safari** 打开本仓库的 Pages 地址（形如 `https://用户名.github.io/仓库名/`）
2. 点底部 **分享** → **添加到主屏幕** → 添加
3. 桌面上会出现靶心图标，点开就是全屏 App，断网可用

> 已添加过的同学：图标是缓存的，更新后请长按旧图标删除，再重新添加一次。

## 与电脑版同步

- **电脑 → 手机（推荐）**：电脑版「设置 → 推送数据到网站」→ 手机版「我的 → 拉取电脑数据」一键覆盖
- 手机 → 电脑：手机版「我的 → 导出备份」→ 发到电脑 → 电脑版「设置 → 从备份恢复」
- 注意：推送的数据放在本仓库 `sync.json`（公开网址），不要推含敏感信息的记录

## 电脑版（Windows 桌面 exe）

`desktop/Jacqueline 工作台.exe` —— 双击即用，不需要装 Python。

- 纯离线，数据存在 exe 同目录的 `workbench_data.json`，不上传
- 功能：首页（今日三件事 / 打卡 / 饮水 / 体重 / 待办 / 倒计时）、今日安排、日历记录（含 2025–2027 法定节假日）、定时提醒、周计划、周期任务、减肥记录、医美清单、习惯打卡（含热力图）、学习番茄、书单、CPA 科目、素材库、自媒体打卡、待办、随笔、全局搜索、设置
- 6 套莫兰迪配色，侧栏底部切换
- 每日一句：417 句阳光词库
- 固定格言：人生，易如反掌

数据文件位置：把 exe 放在任意文件夹，它会在同目录生成 `workbench_data.json` 和 `backups\`（自动备份，保留 30 份）。
源码在 `desktop/源码/`，有 Python 环境的话 `pip install pyinstaller` 后可直接改。

## 每天怎么用

| 页面 | 干什么 |
|---|---|
| 今日 | 写「今日三件事」；看今天的提醒、假期、倒计时 |
| 快捷入口 | 首页第一张卡，点图标直达项目/学习/打卡/体重/待办 |
| 打卡 | 一行一个习惯，点整行打勾，右边是连续天数 |
| 体重 | 记体重（自动画趋势）；8 个杯子点一下记喝水 |
| 待办 | 想到就加，做完点掉 |
| 我的 | 写心情和当天记录；换配色；导出/恢复数据 |

**项目清单**：新增项目 → 填名称/状态/进度/负责人/对接人/截止/下一步 → 保存；点「跟进 1/2」展开勾选或继续加事项。

**学习清单**：按分类添加条目（CPA专业 / AI / 医学健康 / 育儿 / 玄学 / 理财 / 心理成长 / 生活美学 / 其他），状态分想学/在学/已学。

## 提醒功能说明

网页 App 在后台不能定时弹通知，所以**提醒走系统日历**：
在电脑版「定时提醒 → 📱 导出到 iPhone 日历」生成 `.ics`，发到 iPhone 点开「添加到日历」，到点由系统提醒，电脑关着也没事。
